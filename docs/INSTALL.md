# 安裝說明（側載）

這個 App 不上架 Google Play，直接安裝 APK 檔。

- 套件名稱：`com.jiapan.smsforwarder`
- 最低系統需求：Android 7.0（API 24）
- 簽章 SHA-1：`AE:60:11:8B:9E:4D:6A:9A:18:04:5C:A6:40:FF:42:28:3C:2E:BB:E4`

安裝前可以先核對簽章，確認 APK 沒被掉包：

```bash
apksigner verify --print-certs SMSForwarder-1.1.0.apk
```

---

## 一、安裝 APK

### 方法 A：手機上直接裝

1. 把 `SMSForwarder-1.1.0.apk` 傳到手機（雲端硬碟、傳輸線、或自己傳給自己的訊息都行）。
2. 用檔案管理員點開這個 APK。
3. 系統會擋下來說「基於安全考量，你的手機不允許安裝來源不明的應用程式」，點**設定**。
4. 開啟該檔案管理員的「**允許安裝未知的應用程式**」，返回後再點一次安裝。
5. 裝完後建議把上一步的開關關掉。

### 方法 B：用 adb（電腦端）

```bash
adb install SMSForwarder-1.1.0.apk
```

## 二、授權簡訊權限

第一次開啟 App 會跳出簡訊權限請求，**必須選允許** — 沒有這個權限就完全收不到簡訊、也不會轉發。

如果不小心點了拒絕，到「設定 → 應用程式 → SMS Forwarder → 權限 → 簡訊」手動開啟。

## 三、設定 Discord Webhook

1. 在 Discord 裡開你要接收訊息的頻道 →「編輯頻道」→「整合」→「Webhook」→「新增 Webhook」→ 複製 Webhook 網址。
2. 回到 App 的**設定**頁，點右下角「新增 Webhook」。
3. 填**名稱**（自己辨識用）和剛剛複製的 **Webhook URL**，按確定。
4. 可以加多組，收到的簡訊會轉發到每一組。
5. 「接收者手機號碼」欄位填這支手機的號碼，只是顯示在轉發訊息的標題上，方便你分辨是哪支小號收到的。按**儲存**。

設好之後，用另一支手機發一則簡訊過來測試。轉發成功的話 Discord 頻道會馬上出現訊息，App 的**記錄**頁也會留下一筆。

## 四、記錄頁

- 可以搜尋發送者或內容
- 可以標星號，並用「只看星號」篩選
- 單筆可刪除（無法復原）

---

## 升級到新版本

直接安裝新的 APK 覆蓋即可，資料會保留。

前提是新 APK 用**同一組 keystore** 簽名。如果簽章不同，系統會拒絕安裝並顯示「應用程式未安裝」之類的錯誤，這時只能先移除舊版再裝新版 — **移除會清掉所有簡訊記錄和 webhook 設定**。

## 已知限制

- 如果手機的預設簡訊 App 不是 Android 內建的那個，可能收不到 `SMS_RECEIVED` 廣播，就不會轉發。
- 系統的省電優化可能會延後轉發。轉發是走 WorkManager，網路不通時會排隊重試，恢復連線後補送。若要求即時，建議到「設定 → 電池」把這個 App 設成不受限制。
